Wire Protocol

Length-prefixed JSON framing over Unix domain sockets. Both Node.js and Python use identical wire format — no protocol negotiation needed.

4-Byte Length Prefix
uint32 BE
Big-endian network byte order
N-Byte JSON Payload (UTF-8)
{
  "id": "uuid-v4",
  "type": "PUBLISH | SUBSCRIBE | DIRECT_SEND | REQUEST | RESPONSE | ...",
  "from": "agent-01",
  "to": "agent-02" | null,
  "topic": "progress" | null,
  "correlationId": "uuid" | null,
  "priority": "HIGH | NORMAL | LOW",
  "timestamp": 1710000000000,
  "payload": { ... any JSON ... }
}
Serialize (Node.js) JS
const json = JSON.stringify(message);
const jsonBuf = Buffer.from(json, "utf-8");
const buf = Buffer.allocUnsafe(4 + jsonBuf.length);
buf.writeUInt32BE(jsonBuf.length, 0);
jsonBuf.copy(buf, 4);
socket.write(buf);
Serialize (Python) PY
json_str = json.dumps(message)
json_bytes = json_str.encode("utf-8")
header = struct.pack(">I", len(json_bytes))
sock.sendall(header + json_bytes)

Message Types

Type Direction Required Fields Description
PUBLISH Agent → Bus → Subscribers topic Broadcast to all topic subscribers
SUBSCRIBE Agent → Bus topic Register interest in a topic
UNSUBSCRIBE Agent → Bus topic Remove topic subscription
DIRECT_SEND Agent → Bus → Agent to Point-to-point message delivery
REQUEST Agent → Bus → Agent to Request expecting correlated response
RESPONSE Agent → Bus → Agent to, correlationId Response to a prior REQUEST
REGISTER Agent → Bus — Agent announces presence
UNREGISTER Agent → Bus — Agent gracefully disconnects
HEARTBEAT Agent ↔ Bus — Liveness probe (every 30s, bus echoes)
ERROR Bus → Agent — Error notification

Integration Points

The IPC layer integrates with six existing modules. All integration is non-fatal — if the bus is unavailable, the system degrades to its original file-based communication.

swarm.mjs

creates →
MessageBus + AgentRegistry

Creates and starts the bus server. Initializes the registry with bus integration hooks. Passes CLAUDE_IPC_SOCKET env to spawned agents. Registers cleanup handler on shutdown.

orchestration.mjs

creates →
OrchestratorControl

Creates privileged orchestrator control channel with auth token. Monitors bus state for agent coordination. Passes IPC socket path to agent spawn configuration.

agent-spawn.mjs

uses →
AgentRegistry

Registers agents in registry on spawn with role, model, capabilities, worktree path. Deregisters agents on exit. Passes CLAUDE_IPC_SOCKET environment variable to child processes.

lifecycle.mjs

creates →
AgentChannel

Connects to bus on agent startup. Publishes agent.lifecycle events (online/offline). Disconnects gracefully during cleanup. All wrapped in try/catch for non-fatal IPC.

telemetry.mjs

creates →
TelemetryChannel

Initializes via TelemetryChannel.init(agentChannel). Routes tool calls, checklist items, memory stats, and progress updates through the batched telemetry bus topic.

agent-entry.mjs

creates →
AgentChannel + TelemetryChannel

Initializes both IPC channel and telemetry routing on agent startup. Entry point for all spawned agent processes to connect to the bus.
